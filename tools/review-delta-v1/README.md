# review-delta-v1 tools

`review_delta_v1.py` owns manifest validation, deterministic Git-history materialization, execution,
Workbench source verification, and saved-result verification. `run.py` and `verify.py` are narrow
entry points for CI.

See [`../../benchmarks/review-delta-v1/README.md`](../../benchmarks/review-delta-v1/README.md) for
the benchmark contract and commands.
